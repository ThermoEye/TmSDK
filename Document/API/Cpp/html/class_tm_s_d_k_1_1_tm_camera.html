◆ BeginAcquisition()

void TmSDK::TmCamera::BeginAcquisition ( )

Start frame acquisition mode.

After Open, a background frame thread already runs for IsConnected. This call enables delivery of frames to a registered callback while acquisition is active. That thread is the only reader of the video device. QueryFrame pops from the same captured-frame queue while callback acquisition is inactive, and returns false while callback acquisition is active.
